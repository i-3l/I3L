1) Download the Arduino IDE
2) Connect LilyGo T-Display-S3 to machine
3) Select the board from the top menu. If a LilyGo T-Display-S3 is not found, you may have to click "Select another board and port" and then set it manually.
4) Install GFX for Arduino Package by:
    - Sketch > Include Library > Manage Libraries
    - Install GFX Library for Arduino by Moon On Our Nation
5) Open resistive_sensor in the IDE and hit the upload button in the top left.
